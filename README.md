# Belts (and more) Animation Freeze - Factorio 2.1 compatibility fork

Unofficial, temporary fork of [BeltsAndMoreAnimationFreeze](https://mods.factorio.com/mod/BeltsAndMoreAnimationFreeze)
so it loads on Factorio 2.1. The original mod has no public source repository; this was
reconstructed from the published 0.1.1 release zip.

- Original authors: Avongard, purple_cpu_chip, FuzzyGames (portal owner: FuzzyGames)
- License: MIT (as declared on the mod portal page for the original mod)
- Mod `name` is unchanged, so existing saves carry over.

Changes from 0.1.1: `factorio_version` 2.1, `base >= 2.1.0`, and the freeze now also covers
`lane-splitter`, `linked-belt` and `loader-1x1` prototypes.

Install: drop the release zip into your mods folder (Windows `%APPDATA%\Factorio\mods`,
Mac `~/Library/Application Support/factorio/mods`).
